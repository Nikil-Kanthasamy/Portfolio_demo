# Nikil K — Business Analyst Portfolio

A responsive, static personal portfolio and career dashboard presenting professional experience, skills, career milestones, and an overview of a Business Analyst career path. The site is designed as a clean, easy-to-navigate introduction for recruiters, hiring teams, and collaborators.

**Live portfolio:** https://nikil-portfolio-demo.vercel.app  
**Repository:** https://github.com/Nikil-Kanthasamy/Portfolio_demo

## Overview

This project turns professional profile information into a compact web portfolio. It provides a single place to review the career overview, experience timeline, skills snapshot, and milestones, with a layout that adapts to desktop and mobile screens.

## Portfolio sections

- **Career overview:** concise introduction and professional positioning
- **Experience timeline:** progression across internship, trainee, and Business Analyst experience
- **Skills snapshot:** visual summary of relevant skills
- **Career milestones:** highlights of professional development
- **Education:** reserved for verified education details

## Intended audience

- Recruiters and hiring managers reviewing Business Analyst candidates
- Professionals and peers interested in the project
- Anyone viewing a practical example of a static portfolio dashboard

## Technology

- HTML for page structure
- CSS for layout, styling, and responsive presentation
- Vanilla JavaScript where interactive behavior is used
- Static hosting on Vercel

The project is intentionally lightweight and does not require a backend, database, package installation, or build process.

## Run locally

1. Clone or download this repository.
2. Open the repository folder.
3. Open `index.html` directly in a modern web browser.

Alternatively, start a local static server:

```bash
python -m http.server 8000
```

Then visit http://localhost:8000.

## Deployment

The portfolio is deployed as a static site on Vercel.

- **Production URL:** https://nikil-portfolio-demo.vercel.app
- **Source repository:** https://github.com/Nikil-Kanthasamy/Portfolio_demo
- **Build command:** not required
- **Output:** repository root

Use the clean production URL above when sharing the portfolio.

## Customization

- Update professional wording and experience details in `index.html`.
- Keep dates, role titles, education, and achievements accurate and verifiable.
- Adjust skill labels and visual indicators to reflect current, honestly self-assessed proficiency.
- Modify the CSS styles to personalize colors, typography, spacing, and layout.
- Add project links or certifications only when the supporting details are available.

## Accuracy and content note

This portfolio is a presentation project. It should only contain accurate, user-confirmed experience, education, skills, certifications, and achievements. Visual skill indicators are illustrative unless they have been explicitly validated. No project names, qualifications, metrics, or credentials should be inferred or invented.
